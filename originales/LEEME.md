# Originales

Las imágenes tal como llegaron, antes de procesarlas para el sitio.

Esta carpeta **no se publica**: queda fuera de `wwwroot`, así que ni se sirve ni
viaja en el despliegue. Está para poder volver a generar las versiones del sitio
—con otro recorte, otro tamaño o mejor calidad— sin tener que pedir de nuevo el
archivo.

| Archivo | Qué se generó a partir de él |
| --- | --- |
| `horacio.jpg` | `wwwroot/imagenes/horacio.webp` (1000 px) y `horacio-min.webp` (140 px) |

La foto original pesa 927 KB. Publicada tal cual habría pesado más que toda la
portada junta, y la ficha se la habría bajado entera para mostrar un círculo de
46 píxeles.
